# Phase 0 — Kickoff + OOP Foundations in C++ & Java

**Why first:** every LLD answer is expressed in objects, ownership and relationships, and the first 20
minutes of every machine-coding round is *modelling*. C++ LLD code is only credible if ownership is
explicit (RAII, `unique_ptr` vs `shared_ptr` vs non-owning pointers), polymorphism is correct (virtual
destructors, no slicing), and values are values (money as integer paise in a `Money` type, not a
`double`). Java is covered alongside because many Indian LLD rounds are run in Java.
**Scaffolding:** hints on request at any rung; Claude offers H0 after ~5 min of silence.
**Reading (after the sessions):** none required. *Effective Modern C++* items 18–22 (smart pointers)
and 23–25 (move semantics) are optional companions to 0.2.

| 0.2.1 | L | **RAII & Exception Safety** — Hook: "`processOrder()` opens a file, locks a mutex, allocates a buffer, and has three early returns plus a call that can throw. | 0.2.2 | L | **Smart Pointers & Ownership Modelling** — Hook: "A `ParkingLot` has floors, floors have spots, a spot knows its parked vehicle, a ticket refers to the spot. Who deletes what? | 0.2.3 | DD | **Rule of 0/3/5 & Move Semantics** — Hook: "A class owns a raw buffer. Copy it, assign it, return it from a function, put it in a `vector` and grow the vector.
